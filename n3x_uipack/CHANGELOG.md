# Changelog

All notable changes to N3X UI Pack will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-23

### Added
- Initial release of N3X UI Pack
- **Notification System**
  - Support for 4 types: success, error, warning, info
  - Customizable position (6 positions available)
  - Progress bar animation
  - Custom duration and icons
  - Multiple animation styles
  - Maximum notification limit

- **Progress Bar/Circle**
  - Two types: bar and circle
  - Cancellable progress
  - Animation support
  - Prop attachment support
  - Percentage display
  - Custom positioning

- **Input Dialog**
  - 5 input types: text, number, textarea, select, checkbox
  - Form validation
  - Required field support
  - Min/max values for numbers
  - Descriptions and placeholders
  - Custom styling

- **Context Menu**
  - Searchable menus
  - Icon support
  - Disabled options
  - Submenu arrows
  - Custom descriptions
  - Close on select option

- **Skill Check**
  - 3 types: circle, bar, keys
  - 4 difficulty presets: easy, medium, hard, extreme
  - Custom difficulty settings
  - Attempts counter
  - Timer display
  - Vibration on fail

- **Text UI**
  - 5 style options
  - 5 position options
  - Icon support
  - Simple string or object input
  - Fade in/out animations

- **Alert Dialog**
  - Custom buttons
  - Cancel option
  - Centered layout
  - Timer support
  - Return value on selection

- **NPC Dialog**
  - Avatar support
  - Typewriter effect
  - Choice system
  - Auto-hide option
  - Custom duration
  - Multiple choice support

- **Radial Menu**
  - 3 styles: honeycomb, circular, grid
  - Up to 8 items
  - Icon and label support
  - Click handlers
  - Custom sizing

- **Configuration System**
  - Theme customization (colors)
  - Component-specific settings
  - Animation controls
  - Performance mode
  - Debug mode
  - ox_lib override option

- **Advanced Features**
  - Automatic ox_lib override
  - Fallback system
  - Performance optimization
  - Caching system
  - Sound effects
  - Blur effects
  - Responsive design

### Documentation
- Comprehensive README with examples
- Usage examples file with all components
- Inline code documentation
- Configuration guide

### Compatibility
- Full ox_lib compatibility
- QBCore support
- ESX support
- Standalone support
- Framework agnostic design
