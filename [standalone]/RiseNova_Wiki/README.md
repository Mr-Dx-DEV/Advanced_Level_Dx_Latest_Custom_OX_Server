# 🚀 RiseNova_Wiki --- Premium In-Game Roleplay Wiki

A modern, clean, fully customisable in-game knowledge panel for QBCore,
ESX, QBOX and standalone.\
Open with **F5** (configurable) and access guides, rules, job
instructions, staff tools and more --- all editable from config.lua.

------------------------------------------------------------------------

## ✨ Features

✔ Sleek modern UI (HTML/CSS/JS)\
✔ Fully customisable via **config.lua**\
✔ Job-restricted pages (PD, EMS, Mechanic)\
✔ Staff-only sections\
✔ Search bar with instant filtering\
✔ Theme system (colors, gradients, accents)\
✔ QBCore / ESX / QBOX / Standalone compatible\
✔ Keybind + command to open (default F5)\
✔ Lightweight & fast

------------------------------------------------------------------------

## 🔧 Installation

1.  Drop the folder into your `resources` directory.\
2.  Ensure the folder is named **RiseNova_Wiki**.\
3.  Add this to your server.cfg:

    ensure RiseNova_Wiki

------------------------------------------------------------------------

## ⚙️ Configuration

All content lives in `config.lua`.\
Pages, categories, jobs, staff pages, themes and keybinds can be changed
easily.
